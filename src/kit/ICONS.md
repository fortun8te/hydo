# Icon audit

Source of truth: `/Users/michael/Downloads/Grok-Bot-shell/extracted-ui-kit/icons.json` (523 real icons, name -> `U+XXXX` codepoint). `src/kit/icons.css` is "Generated from icons.json" per its own header comment, so it already covers all 523 real names.

## Method

1. Literal usage: `grep -rhoE 'gb-icon-[a-z0-9-]+' src/ | sort -u` -> 523 literal class names (className strings written directly in JSX/CSS).
2. Dynamic usage: three call sites build the class name at runtime instead of writing it literally -
   - `src/kit/ui.jsx:33` -> `gb-icon-${item.icon}` (DialogNav items)
   - `src/screens/CommandPalette.jsx:103` -> `gb-icon-${cmd.icon}`
   - `src/screens/Plugins.jsx:754` -> `gb-icon-${test.ok ? "check-circle" : "exclamation-circle"}`
   Traced the `icon:` string literals feeding those props (CommandPalette.jsx, Settings.jsx) and folded them in: `plus`, `magnifying-glass`, `settings-gear`, `alarm-clock`, `puzzle-piece`, `layout-sidebar-left`, `chart-bars`, `cloud-arrow-down`, `check-circle`, `exclamation-circle`. All 10 were already defined - no gap there.
3. Total distinct icon classes actually reachable at runtime: **525**.
4. Diffed against every `.gb-icon-*::before` rule already in `icons.css` (523 rules pre-fix), then cross-checked each survivor against `icons.json` directly (not just against icons.css) per the brief's "verify, don't trust" instruction.

## Result

- **525** distinct icon classes used across `src/`.
- **523** were already defined in `icons.css` and matched a real name in `icons.json`. This includes every name on the suspect list in the brief (`hash`, `chart-bars`, `cloud-arrow-down`, `plug-slash`, `chevrons-right`, `speaker-waves`, `i-circle`, `question-circle`, `alarm-clock`, `device-mobile`, `star-full`, `remove-close`, `layout-sidebar-left`, `magnifying-glass`) **except** `check` and `hash` themselves — see below. Those were false alarms; the icons.css generation was already complete for them.
- **2** were used but undefined, and neither exists anywhere in the 523-name `icons.json` authority (there is no `hash` icon and no bare `check` icon in the real Cursor icon set — only `check-circle`, `check-square`, etc.):

| class | used at | real icon? | fix |
|---|---|---|---|
| `gb-icon-hash` | `src/screens/Composer.jsx:63`, `src/screens/Shell.jsx:203`, `src/screens/Sidebar.jsx:20` — the "#" channel glyph | no | **Aliased** to `people-3` (`U+F474`) — three-person glyph reads as "a group/channel" in the same way a hash does, and there's no dedicated hash/number-sign icon in the kit. |
| `gb-icon-check` | `src/screens/ChannelRail.jsx:65` — toggle state opposite of `gb-icon-plus` when a member is already in a channel | no | **Aliased** to `check-circle` (`U+EDBA`) — closest real checkmark; visually a checkmark in a circle rather than bare, but unambiguous as "selected". |
- **0** unresolved. Both gaps got a working alias rule appended to the bottom of `icons.css`.

## What changed in icons.css

Appended two alias rules at the end of the file (after the generated block, clearly commented as aliases, so a future re-generation from icons.json doesn't silently eat them):

```css
.gb-icon-hash::before { content: "\F474"; }  /* alias -> people-3 */
.gb-icon-check::before { content: "\EDBA"; } /* alias -> check-circle */
```

## For the owning agents (do not rename for me, but consider switching)

- **Composer.jsx / Shell.jsx / Sidebar.jsx** (channel "#" glyph): the alias makes `gb-icon-hash` render correctly right now (three-person glyph). If you want the *literal* correct-est real icon instead of an alias, there isn't a truer one in the 523 — `people-3` is genuinely the closest match, so switching the literal class name to `gb-icon-people-3` is equivalent to keeping `gb-icon-hash`; no action needed unless you want the class name itself to read honestly (recommend switching to `gb-icon-people-3` for clarity, since a reader of the JSX might otherwise assume a real "hash" glyph exists).
- **ChannelRail.jsx** (member-toggle check icon): consider switching `gb-icon-check` to `gb-icon-check-circle` directly in the JSX — that is the exact icon the alias now points to, and using the real name removes the indirection.
